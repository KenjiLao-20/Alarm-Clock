# ⏰ Alarm Clock

A modern, feature-rich alarm clock web application with real-time countdown, snooze functionality, and beautiful UI animations.

<br>

## ✨ Features

<br>

- **Real-time Clock** – Live updating current time and date display
- **Multiple Alarms** – Set and manage unlimited alarms
- **Custom Labels** – Give each alarm a custom name (e.g., "Wake Up", "Meeting")
- **Snooze Function** – 5-minute snooze with auto-rescheduling
- **Countdown Timer** – Shows time remaining until each alarm
- **Browser Notifications** – Desktop notifications when alarm triggers
- **Sound Alerts** – Pleasant alarm sound using Web Audio API
- **Pause/Resume** – Temporarily disable any alarm
- **Responsive Design** – Works perfectly on mobile and desktop
- **Dark Theme** – Modern dark UI with gradient effects

<br>

## 🎮 How to Use

<br>

1. **Set Alarm Time** – Use the time picker to select your desired time
2. **Add Label (Optional)** – Give your alarm a custom name
3. **Click "Add Alarm"** – Your alarm appears in the list
4. **Monitor Countdown** – See time remaining until alarm triggers
5. **When Alarm Rings** – Choose "Snooze" (5 min) or "Dismiss"

<br>

## 🎨 Alarm Controls

<br>

| Control | Function |
|---------|----------|
| **Pause** | Temporarily disable an alarm |
| **Resume** | Re-enable a paused alarm |
| **Delete** | Permanently remove an alarm |
| **Snooze** | Delay alarm by 5 minutes |
| **Dismiss** | Stop current alarm completely |

<br>

## 🔔 Notification Permission

<br>

The app will request notification permission when you add your first alarm. Allow notifications to receive desktop alerts when alarms trigger.
